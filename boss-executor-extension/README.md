# FineJob BOSS 执行器

这是 FineJob 的独立 Chrome 执行器。它与 FineJob 本机后端配对，负责按根目录 `test.md` 定义的任务流程执行 BOSS 默认招呼，并提供自动代聊的消息观察、草稿确认和文本发送能力。

## 当前能力

- WXT + Manifest V3 + Vue 3 + TypeScript 独立工程。
- MAIN → Content → Background 三层隔离通信。
- 通过 `127.0.0.1:8000` 与 FineJob 完成本机配对、心跳、完整任务列表同步和结果回传。
- 插件保存后端下发的完整任务列表，用于页面岗位身份匹配和状态显示。
- 页面匹配只使用岗位 ID、登录状态和沟通状态等必要信息。
- 匹配成功后回传任务 ID，执行结果由后端更新并重新下发任务列表。
- BOSS 默认招呼使用账号当前默认招呼语，不发送 FineJob 自定义文本。
- 页面异常、登录失效、验证码、频控和岗位不匹配时停止执行并回传原因。
- 自动代聊监听、草稿生成和人工确认发送使用三项独立开关，默认全部关闭。
- 监听开启后，只观察新出现的 `chat` MQTT/Techwolf Protobuf 消息，不读取 BOSS 历史聊天。
- 联系人和岗位映射使用单联系人元数据接口，不把联系人列表当作聊天历史同步。
- 同账号多个沟通页通过 Background 协调标签页，按账号隔离并保持发送权限一致。
- 人工确认后的文本发送使用 BOSS `wt`、MQTT 连接、Protobuf 文本消息和 `chat` 主题发布方式。
- MQTT `publish` 未抛错只回写 `accepted`；失败或未知结果均回传，不自动重复发送。

岗位页面的打开由 FineJob 通过专用 Chrome 的 CDP 完成。普通“在专用浏览器打开”只用于查看，不会创建或执行打招呼任务。

## 安装与构建

```powershell
pnpm install --config.offline=false
pnpm run typecheck
pnpm run test
pnpm run build
```

Chrome 未打包目录：

```text
.output/chrome-mv3/
```

## 在 Chrome 中加载

1. 打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择 `.output/chrome-mv3`。
5. 打开或刷新 FineJob 专用 Chrome 中的 BOSS 页面。
6. 在 FineJob 待确认页生成六位配对码，再输入插件面板。
7. 确认插件已收到完整任务列表；插件按 BOSS 页面岗位 ID 匹配任务。
8. 使用自动代聊时保持至少一个 BOSS 沟通页打开，并在 FineJob“自动代聊”页面分别开启所需权限。

## 运行流程

```text
FineJob 生成执行任务
→ 插件同步完整任务列表
→ 插件读取 BOSS 页面岗位身份
→ 页面匹配时回传任务 ID
→ FineJob 更新任务状态
→ 插件执行 BOSS 默认招呼
→ 插件回传成功、失败或未知结果
→ FineJob 更新任务列表并继续页面匹配
```

页面未匹配时，插件请求 FineJob 打开任务页面；页面打开结果返回后，插件继续读取岗位身份并进行匹配。连续匹配失败时，插件按 `test.md` 规定发送心跳并再次请求打开页面。

自动代聊流程：

```text
用户开启消息监听
→ 沟通页标签观察新消息并去重上报
→ FineJob 生成草稿
→ 用户编辑并点击确认发送
→ 后端执行版本校验并创建发送任务
→ 标签页通过 MQTT chat 主题提交文本
→ accepted / failed / unknown 回写本地会话
```

## 安全边界

- FineJob 后端维护任务状态，插件只保存后端下发的完整任务列表副本用于执行和展示。
- 配对令牌只保存在扩展存储与 FineJob 本机数据库校验数据中，不发送到 BOSS 页面。
- BOSS token 只在 MAIN World 发起单次平台请求时使用，不回传 FineJob，不写入插件面板或日志。
- 不读取 BOSS 历史消息；监听关闭时不解析或持久化新消息正文。
- 不自动确认 AI 草稿；自定义文本只能来自用户点击确认的版本。
- 不自动发送简历、图片、联系方式或面试操作。
- 不处理或绕过验证码、登录失效、频控和平台安全机制。
- 不使用可信事件伪造、webdriver隐藏、随机鼠标轨迹等反检测手段。
- 每条自动代聊真实文本都必须由用户在执行当时点击确认。

实现与验收边界见根目录 `test.md` 和《自动代聊功能具体执行方案.md》。
